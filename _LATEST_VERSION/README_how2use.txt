Here's how to use the current version (updated December 2025)

*The MacOS version is currently unworking*

1. Create a folder containing all the files
2. Download the files in the folder (either Windows or MacOS depending on your operating system) and put BOTH files into the folder from 1.
3. double click on _Run_Selector.bat (Windows) or _Run_Selector.command (MacOS)
4. type/paste the selected file IDs into the program
5. Done! - the program will create folder _Selected_Files with all of the selected files
